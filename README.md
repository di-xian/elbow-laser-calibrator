# 弯头激光切割校正工具 V5.0

根据用户提供的两段 HTML/JavaScript 合并，修复脚本衔接，补齐 PWA 配置、图标、离线缓存与缓存准备状态。修复零偏差提示与仅填写数字备注也可保存的问题。保留原有计算公式；尚未验证公式与具体图纸测量基准、机床标定数据的对应关系。

## 上传目录

```text
仓库根目录/
├── index.html
├── README.md
├── manifest.webmanifest
├── sw.js
├── .nojekyll
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

不要仅上传 ZIP，也不要让 index.html 外面再多套一层文件夹。图标文件夹要保留原结构。.nojekyll 为隐藏文件，上传时也建议包含。

## GitHub 发布（电脑操作）

1. 确认仓库名称与公开/私有选项。GitHub Free 可使用公开仓库启用 Pages；公开仓库中的代码对其他人可见。
2. 登录 GitHub，右上角 + → New repository，填写仓库名。可勾选 Add a README file，再点击 Create repository。
3. 仓库 Code 页 → Add file → Upload files，将本目录里的所有文件和 icons 文件夹拖入。若已有默认 README，用本包说明替换即可。填写提交说明，点击 Commit changes。
4. 打开仓库 Settings → Pages。Source 选 Deploy from a branch；Branch 选 main，目录选 /(root)，点击 Save。
5. 等待 Pages 显示发布完成和 Visit site。以实际显示的网址为准，项目网址通常是 https://用户名.github.io/仓库名/ 。
6. 打开网站，确认页面顶部出现“离线文件已缓存”，再检查计算与保存功能。如部署失败，查看仓库 Actions 中的 pages build and deployment。

## 安卓安装和离线验收

1. 使用手机 Chrome 打开实际发布的 HTTPS 网站。
2. 等待顶部“离线文件已缓存”。从右上角 ⋮ 菜单选“安装应用”或“添加到主屏幕”（不同版本文字可能不同），完成确认。
3. 做一条示例试切记录，保存后导出 JSON，确认备份文件可打开。
4. 关闭应用全部页面；开启飞行模式，并确认 Wi-Fi 也已关闭。从桌面图标重新打开工具，测试计算、查看旧记录及保存新记录。
5. 只有重新打开和功能测试通过，才说明该手机离线可用。安装成功、出现桌面图标不等于离线验收完成。

首次加载和安装需要联网。之后已缓存的页面与计算可以离线运行。本包不包含 APK，也不上传生产记录。

## 本地直接使用

双击 index.html 可打开计算界面，计算代码与样式都内嵌在 HTML 中。file:// 模式不能安装 service worker；本机记录是否长期保留取决于浏览器，务必导出备份。安装到手机桌面请使用 Pages 的 HTTPS 网址。

## 使用与数据

- 先输入客户尺寸和公差；不考核的尺寸选择“不要求 / 忽略”。
- 理论计算需提供实测中心线 R。理论尺寸使用理想圆弧与约定的投影基准，不能自动等同实际平台翻面测量或机床参数。
- 保存试切需至少一项测量值；A/B 四点高度及成品角度未测全时，不能判为必保项目全部合格。
- 历史趋势仅供试切参考，不是已标定的机床补偿值。所有公式和趋势仍需现场核对。
- 记录保存在当前浏览器的 localStorage 中。更换设备、浏览器或网址不会自动迁移，GitHub 不备份这些记录。
- JSON 用于恢复，CSV 用于表格查看。导入 JSON 会在确认后替换当前记录，请先备份。

## 后续维护

修改页面、安装配置或图标后，同时更新 sw.js 中的 VERSION 再提交。网页检查到新版本后，关闭此站点的全部页面，再联网重开，以完成更新。正式使用前先备份记录。
